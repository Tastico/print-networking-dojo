# Print Networking Dojo

Interactive, self-contained networking trainer built for print and IT field engineers. One HTML file, zero dependencies, works offline. Open it in any browser and it runs.

## Why this exists

Field engineers get handed printers and MFPs and are expected to debug IP conflicts, firewalls, DNS, and raw socket printing on the spot. Most networking courses are written for datacenter people. This one is written for the person standing in front of a machine with a laptop and a cable tester.

## Modules (18)

1. IP Subnets
2. Ports
3. TCP/UDP
4. SSL/TLS
5. RAW 9100 / LPR
6. SNMP / CPCA
7. SMB / Scan-to-Folder
8. Firewalls / VLANs
9. DNS / DHCP / NAT
10. Device Agents
11. Printer Languages
12. Printer Drivers
13. Print Management
14. Troubleshooting
15. Cabling
16. Auth / ACL
17. Mobile Printing
18. Security Hardening

## Features

- Graded multiple-choice quizzes with instant feedback
- Scenario labs (fix the print job that is failing, and explain why)
- Progress tracking saved in the browser
- Reference cards for ports, protocols, and common failure modes
- No server, no install, no internet needed

## Use it

Clone or download the repo and open `interactive-dojo.html` in a browser. That is it.
